Independent product concept · Workflow design · 2026

La Cosa Nostra
Design Studio

Make AI-assisted work understandable: who owns the task, what state it is in, and what still needs a human decision.

My contribution
Workflow structure, task ownership, review gates, and status language
Project type
Independent product concept with foundational implementation work
Boundary
Workflow concept and foundational implementation; not a fully connected commercial service

The problem

When work passes between several AI tools and project tracks, ownership and review status can become difficult to follow. A proposed action, an approved action, and a completed action should not look the same.

Design response

Make ownership explicit.

A mission has a defined scope, a coordinator, bounded specialist responsibilities, and a human approval point.

Expose the actual state.

Capability and progress labels distinguish available functionality, demonstrations, unfinished work, and unavailable providers.

Keep projects separated.

Project context and run records have defined boundaries. Review history supports an explanation of what happened instead of relying on a polished completion message.

Evidence & status

The project documentation records foundational builds, a mission lifecycle, approval records, and test work. This portfolio presents the workflow design and its rationale; it does not claim a fully connected commercial orchestration service.

The design lesson is that approval, accountability, and recovery belong in the interface, not only in implementation notes.
