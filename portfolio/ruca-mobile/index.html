Not a smaller desktop.

Desktop RUCA remains the system and telemetry authority. The companion becomes the touch experience authority. That changes density, navigation, feedback, and what deserves immediate attention.

Five destinations preserve the system vocabulary: HOME for configurable reach, MEDIA for playback, SYSTEM HEART for selective condition, COMMAND DECK for supported desktop actions, and DIAGNOSTICS for connection and telemetry truth.

Failure is part of the design.

Reachable does not automatically mean current. Connection state and telemetry freshness remain separate. Missing information stays missing, and loss of the desktop does not destroy the user’s configured HOME layout.

Commands expose target, availability, confirmation, and outcome. Haptics can reinforce feedback, but visible state remains authoritative.

Evidence boundary.

The September Android source proves the current implementation work exists, but the archive available to this public release contains older installed-device screenshots alongside newer source. I will not relabel July device captures as September proof. The current V1 reviewer renders above are therefore identified as product-direction evidence, not fake installed-device screenshots.

That distinction is deliberate product honesty, not missing polish.
