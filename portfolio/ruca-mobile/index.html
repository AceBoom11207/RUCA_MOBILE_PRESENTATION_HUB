Reassign the work
for touch.

The desktop remains the source of system telemetry and machine actions. The companion owns the handheld interaction: what deserves immediate attention, what can fit comfortably under a finger, and how the user gets back.

Six HOME ports provide configurable access. Media, System Heart, Command Deck, and Diagnostics keep their own responsibilities rather than crowding every action onto HOME.

Connection is more
than a green dot.

A reachable desktop can still have stale or unavailable telemetry. Connection and data freshness remain separate, and an interrupted connection preserves the user’s HOME configuration.

The browser demo lets reviewers inspect these states. Commands and playback responses are simulated and identified as such.
